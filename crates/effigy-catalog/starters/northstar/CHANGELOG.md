# Changelog

All notable user-facing changes are tracked in this file.

Format follows the Northstar Changelog Profile:

- **Breaking** — CLI/API/config changes, removed features
- **Added** — new features, commands, options
- **Changed** — non-breaking modifications to existing behavior
- **Fixed** — bug fixes

The `[Unreleased]` section accumulates changes until a release is cut.
