# Vision

This folder holds the product vision for this repo. The docs-policy
index declared in `effigy.toml` uses the `Vision Artifacts` section
below as the source of truth for `effigy docs check-index`.

## Vision Artifacts

- [`001-product-vision.md`](001-product-vision.md) — current product
  vision (long-term outcome, constraints, target envelope, next task).

Add new vision documents as numbered entries. Keep the current vision
artifact explicit — do not let the index go stale.

## How vision relates to roadmaps and logs

- Vision — long-horizon outcome and strategic constraints.
- Roadmaps — milestone batches and sequencing under that vision.
- Logs — evidence of what shipped and why.

Do not collapse these into one generic planning note.
