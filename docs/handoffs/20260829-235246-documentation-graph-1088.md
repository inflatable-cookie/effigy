documentation graph lane. The important decision is that repositories own their
documentation semantics in `effigy.toml`; Northstar supplies one committed
profile later, but generic runtime code does not know Northstar vocabulary.

thread. Implement only the structural foundation in card `1088`. The public

## Why It Matters

Effigy's graph can already find Markdown text and links, but it cannot tell a
live contract from an archived spec or return an exact section instead of a
whole document. This batch creates the generic, deterministic substrate needed
for faster agent retrieval without a second database, remote inference, or a
Northstar runtime dependency.
