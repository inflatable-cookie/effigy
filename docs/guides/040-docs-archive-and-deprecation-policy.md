# 040 — Documentation retirement

Keep current truth in [knowledge](../knowledge/README.md) and user instructions in [guides](README.md). When a concept ends, name it in [retired.toml](../knowledge/retired.toml), update live references, and run `effigy skill run northstar-lean/retired-concepts`.

Git history holds completed audits, research, delivery records, and old planning. A still-useful procedure belongs in knowledge. An unresolved lead belongs in [triage](../triage/README.md). Guide URLs used by consumers stay stable: update their content or leave a short pointer to the replacement.
