# 040 — Documentation retirement

Keep current truth in [knowledge](../knowledge/README.md) and user instructions in [guides](README.md). When a concept ends, remove it and update live references.

Git history holds completed audits, research, delivery records, and old planning. A still-useful procedure belongs in knowledge. An unresolved lead belongs in Queue (`lead.add`). Guide URLs used by consumers stay stable: update their content or leave a short pointer to the replacement.
