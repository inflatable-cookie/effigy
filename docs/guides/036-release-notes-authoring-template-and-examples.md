# 036 — Release notes

Use `effigy changelog extract CHANGELOG.md --version X.Y.Z` as the draft baseline. For a human review, summarize user-visible changes, compatibility or migration steps, validation on the exact candidate commit, and any known limitation. Tom approves the notes before release execution. Publish the reviewed text with the GitHub release.

The [release procedure](../knowledge/contracts/release.md) owns the full sequence. The [distribution policy](049-ci-binary-distribution-and-release-protocol.md) owns binary channels and versioning.
