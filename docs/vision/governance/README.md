# Vision Governance

Live governance surfaces for Effigy vision artifacts. Templates live in
numbered vision docs (`009`, `015`, `017`, `018`); this folder holds populated,
reviewable state.

## Surfaces

- [`artifact-status-register.md`](./artifact-status-register.md) — lifecycle
  status for vision artifacts `001`–`020`
- [`decision-record-index.md`](./decision-record-index.md) — searchable index
  of strategic decision records

Decision record bodies live in [`../decisions/`](../decisions/).

## Cadence

- **Artifact register** — review monthly; update `Last Reviewed` on change
- **Decision index** — update when a decision opens, stabilizes, or reverses
- **Governance review** — monthly using template `009`; store under
  `docs/logs/<month>/`

## Working Rule

Governance surfaces inform planning and release posture. They do not authorize
execution, override contracts, or replace ready batch cards.
