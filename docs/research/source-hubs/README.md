# Source Hubs

Curated source maps and source-quality hierarchy.

## Purpose

Source hubs index the best available sources for research areas. They don't synthesize findings (that's value tracks) — they map where to find reliable information.

## Structure

Each source map follows the pattern: `NNN-area-source-map-vN.md`

## Source Quality Hierarchy

### Tier 1: Primary Sources
- Official documentation
- Release notes and changelogs
- Source code repositories
- API references
- Technical talks with recordings/slides
- Academic papers

### Tier 2: First-Party Technical Content
- Engineering blogs (technical depth)
- Conference presentations
- SDK/protocol documentation
- Official migration guides

### Tier 3: Practitioner Analysis
- Detailed migration write-ups
- Benchmark studies with methodology
- Production postmortems
- Comparative analyses

### Tier 4: Community Synthesis
- Curated awesome-lists (when maintained)
- Discussion threads with source links
- Quickstart tutorials (for orientation)

### Tier 5: Avoid for Research
- Hype announcements without details
- Unverified performance claims
- Outdated documentation
- Opinion without evidence
