# Research Templates

Reusable templates for Effigy's comparative task runner research program.

## Available Templates

- [`tool-dossier-template.md`](./tool-dossier-template.md) — Per-tool specimen analysis
- [`value-track-synthesis-template.md`](./value-track-synthesis-template.md) — Cross-tool synthesis by problem area
- [`effigy-translation-memo-template.md`](./effigy-translation-memo-template.md) — Effigy-facing recommendations
- [`implementation-decision-record.md`](./implementation-decision-record.md) — Durable implementation traceability

## Working Rule

Use these templates to keep source quality, confidence, tradeoffs, and Effigy implications explicit across every research batch.
Use the implementation decision record when a build decision needs explicit traceability back to memos, tracks, dossiers, or prototype findings.

## Template Usage Flow

1. **Start with dossier** when encountering a new tool
2. **Move to value-track synthesis** when comparing 2+ tools on same problem
3. **Write translation memo** when ready to recommend specific Effigy action
