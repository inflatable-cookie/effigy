# 019 - v0.3.x Release Foundation and v1.0 Readiness Assessment

Generation: `g03`

Status: Complete
Owner: Platform
Created: 2026-05-02
Depends on: 018

## Problem

The runtime/container core is now hardened enough to justify `v1.0`
preparation, but Effigy still lacks an explicit stable release contract for
that transition.

The old `v0.x` release contract was good enough while core behavior was still
moving. It is not the right authority surface for a stable release line.

## Goal

Assess whether the repo is ready for a `v1.0` release contract, and if not,
leave the `v0.x` contract in place with a clear record of what foundation
work was completed.

## Scope

- evaluate the current release surface against a hypothetical `v1.0` contract
- document what is now stable enough to promise:
  - CLI invocation stability
  - config compatibility
  - JSON envelope and machine-contract stability
  - release/install verification paths
  - bounded deployment export surfaces that are already shipped
- document what still needs work before `v1.0`:
  - operator-owned Decodelabs production strategy
  - backlog features and exploratory channels
  - additional tidy-up and feature rollout before a stable line
- keep the live `v0.x` release contract as the governing authority surface

## Non-Goals

- publishing `v1.0` now
- replacing the `v0.x` contract with a `v1.0` contract before the product is
  ready
- widening product scope just to make the release contract look larger
- reopening the runtime/container hardening lane

## Exit Condition

This milestone is complete when:

- the runtime/container hardening foundation is documented and proven
- the `v0.x` release contract remains the live authority surface
- the docs front doors accurately reflect that Effigy is still in `v0.x`
  with a stronger foundation
- a clear boundary exists between what is stable now and what needs more work

## Outcome

The `v0.x` release contract in `docs/roadmaps/backlog/release-contract-v0.md`
remains the governing authority surface. The v1.0 contract is intentionally
deferred until additional features and tidy-up work are shipped.

## Next Task

Continue in `v0.x` release pattern. Revisit `v1.0` contract planning after:
- remaining g03 roadmap items are complete
- at least one more minor release cycle validates the hardened foundation
- no major migration pain is reported across active workspaces
