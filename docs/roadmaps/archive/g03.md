# g03 — Production Export and Runtime Hardening

Status: archived
Kind: roll-up
Succeeded by: `g04`

## Generation intent and boundary

`g03` made production deployment export honest and provider-neutral while
converging Effigy's runtime, container, execution, and artifact boundaries.

## Shipped outcomes

- Neutral deployment model with Underlay, Render, and Railway export paths and
  an explicit operator-owned Decodelabs production boundary.
- Shared runtime preparation, execution binding, repo targeting, interactive
  ownership, error taxonomy, and regression/stress proof.
- Distribution-channel proof, first-publish closeout, manifest pruning,
  documentation repair, and runner decomposition.
- Universal runtime context, container-manager facade, canonical execution
  requests, caller migration, and artifact seed/apply/capture substrate.
