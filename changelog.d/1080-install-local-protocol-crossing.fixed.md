`effigy install:local` now succeeds when the new build crosses a helper protocol bump, such as upgrading from v0.14.1 to v0.15. The install replaced the active binary before its last steps ran, so the still-running previous binary could not start its next step and exited 1 after activation, and a retry overwrote the preserved rollback binary with the new build. The active binary is now replaced in the final step, after the version, source receipt and launcher are staged, and nothing starts after it. A rerun of the same build keeps the existing rollback binary instead of replacing it. Customized launchers and custom symlinks at the launcher path are still left untouched.
