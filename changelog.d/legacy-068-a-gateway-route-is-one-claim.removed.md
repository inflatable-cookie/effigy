**Breaking:** **A gateway route is one claim: `domain -> (checkout path, target)`.** The same checkout path always replaces its own route. Another checkout takes the domain over automatically when the recorded path is missing or its target does not accept a TCP connection within 200 ms, logging one line; otherwise the write is refused naming the other checkout and the command that stops it. An unreadable or unmounted path is unknown, so its routes stay. `down`, `retire` and settle remove the checkout's routes by path. `effigy gateway repair` and `effigy gateway recover` are retired, certificates are a cache that `down` and `retire` keep, and no separate loopback assignment or route lock is recorded.
