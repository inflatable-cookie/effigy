**The standard execution pipeline carries facts instead of re-reading them from text.** A supervised suite's result now carries the exit code the session observed, so `effigy test` reports the code even when recording it in the run journal failed, and no consumer parses an `exit=` display record back into a status. A task run's secret values, the aliases resolved in them and the values it would otherwise inherit are resolved in one place (`task_secrets` for the delivery policy, the host-alias owner for the resolution) instead of three near-copies across the standard, sequence and managed routes. A local-dev vault read now distinguishes "this machine has no local-dev key yet" from an unreadable vault or an unsafe key, so the second kind fails with its own message instead of hiding behind an interactive upgrade prompt. `effigy config inspect --json` propagates a selected value's render error rather than reporting a placeholder, and the JSON and text forms share the one rendering.
