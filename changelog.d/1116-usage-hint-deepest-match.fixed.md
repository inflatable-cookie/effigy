Fixed `usage_hint` falsely reporting `` `effigy tasks qa-group` is not a form: did you mean `qa-groups`? `` when a `tasks qa-group run` invocation failed on a trailing argument or unknown flag. Positional words that some usage line matches literally are now treated as already valid, so sibling forms can no longer blame them, and a fully matching command reports its own usage lines with the unknown flag instead of a sibling suggestion. Genuine subcommand typos still suggest the closest form.
