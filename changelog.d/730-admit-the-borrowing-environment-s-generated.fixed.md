Admit the borrowing environment's generated `data_from` volumes to the Colima nerdctl mount-budget preflight (effigy#730). Preflight now models the one supported external volume definition — `{owner_volume_name: {external: true}}`, optionally repeating that same platform name as `name` — and estimates the owner's platform volume path instead of adding this project's prefix, so a within-budget hybrid environment is admitted. Unknown external names, aliases, `external: false` or malformed external values, driver options, conflicting redefinitions and unresolved interpolation still refuse before apply, and admission only reads: borrowed volumes stay unowned, uncreated, unremoved and unrelabelled.
