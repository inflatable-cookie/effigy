**Breaking:** **Upgrading from v0.14.1 imports nothing.** The first `up` reconciles a running v0.14.1 stack through the ordinary apply: Compose recreates each service whose labels or render changed, once, on the same named volumes, so the data stays. Lifecycle markers, leases, old status history and lock files are ignored, never changed and never deleted. The environment importer, the `effigy run migrate` report and the PID-only v0.14 refusals are gone. [Guide 085](docs/guides/085-v0.15.0-consumer-migration.md#upgrading-from-v0141) documents the proven steps.
