`effigy container down --project <PROJECT> --profile <PROFILE> [--volumes]` tears down one project's Effigy stack on one Colima profile from any directory, without a checkout or `effigy.toml`. It removes the project's labelled containers and networks, and its volumes (including persistent ones) only with `--volumes`. A stopped or unreachable profile is an error rather than a silent skip, and the same teardown is available in-process for Barge's lease sweep.
