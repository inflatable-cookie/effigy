**Breaking:** **Bootstrap is rebuilt around task selectors and pinned sources.** `run` is `setup` (an ordered list of task selectors), `start` takes one selector, `submodules` is a boolean, `[[bootstrap.children]]` becomes a pinned `[sources.<name>]` table, `bootstrap deps sync`, `--db-seed`, `--fresh`, `teardown`, `--backend` and `--start` are gone. A v0.14.1 manifest still loads and Effigy prints one deprecation notice per manifest for this release.
