`~/.effigy/config.toml` can set bundle inputs for the whole machine. A `[bundle.<name>]` block, matched on the bundle's declared name for a path, Git or OCI base exactly as `library_mounts` already matches, accepts `inputs`: values for that bundle's declared `[[inputs]]`. They sit above the bundle's own `default` and below the project's `[bundle]` keys and `effigy.local.toml`, so one machine-local edit (for example `inputs = { php_version = "8.5" }`) moves every project using the bundle while a repo that sets a value keeps it. Values are validated against the declared input names and types: an undeclared or wrong-typed value is ignored with a warning naming the file, the bundle and the input rather than failing every checkout that shares the file, and a block for a bundle the project does not use does nothing. `effigy config inspect` reports each effective input and its source (`php_version = 8.5 (user config)`), and `--json` carries the same facts under `bundle_inputs`.
