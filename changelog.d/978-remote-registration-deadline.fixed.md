A remote task whose workload deadline expires while its session is still registering no longer abandons that session. Identity, intent, client spawn and registration run inside the workload deadline plus the launch's own stop grace, and a registration that arrives there is recorded and then stopped under the already-expired deadline, so the run settles as timed out with its session stopped and settled instead of left unowned. A registration that already arrived is never discarded for a deadline, and a launch that registers nothing in that window still refuses and leaves the intent to settlement's nonce recovery (effigy#978).
