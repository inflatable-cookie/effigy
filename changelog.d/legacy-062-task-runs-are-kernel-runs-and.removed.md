**Breaking:** **Task runs are kernel runs, and Effigy's flags go before the task.** `effigy [--json] [--plan] [--repo <PATH>] [--lock-wait-ms <MS>] [--env-schema <PATH>] <task> [args]`. Everything after the task name belongs to the task, so `effigy lint --json` reaches the linter; `<task> --plan` and `<task> --json` are still read as Effigy's for this release, with a note. One task identity has one lock, held exactly while its run lives and released when it exits, `kill -9` included: a conflict names the holder and exits 75. `effigy tasks unlock` is gone.
