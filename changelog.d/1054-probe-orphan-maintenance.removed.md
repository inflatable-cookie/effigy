Automatic cleanup of a probe that outlives both its observer and its backup guard is removed: a probe's environment marker alone never granted host signal authority, so orphan maintenance could only be reached from a test fixture and an orphaned probe now needs operator cleanup. A parked sentinel also publishes its diagnostic snapshot once instead of rewriting the same bytes every 250 ms, which changes no output: `run status`, `run stop`, a lock-wait timeout and `doctor` name the holder as before.
