Process command lines and the managed process table are now read in-process on macOS through the kernel's own `KERN_PROCARGS2` and public libproc interfaces instead of the setuid `/bin/ps`, which `sandbox-exec` refuses to execute with `EPERM`. Gateway target validation therefore names Colima/Lima's `ssh` ControlMaster (`ssh: …/.colima/_lima/…/ssh.sock [mux]`) as the container runtime's own port forwarder rather than an unrelated host listener, so `effigy container up` works inside a Seatbelt profile, and suite reporting and process-tree supervision keep working under the same profile.
