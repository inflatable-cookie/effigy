Process custody proves the recorded group anchor before it records a receipt and again immediately before the workload `go` byte: the anchor's generation, readable custody nonce, group membership and start order must all verify. An unproven anchor now refuses the spawn with no receipt and no exec, and the blocked pre-exec child is reaped. A retained memory backup re-proves its own exact incarnation before it is sent a custody receipt, so a backup that exited or was replaced gets no frame and the refusal names the retained guard instead of reporting a broken pipe. A memory-backup receipt frame now names a per-guard request number that is reserved before the frame is written and never reused, so a lost or late acknowledgement can never answer a later receipt. The helper handshake protocol is version 3: an older helper binary and this one refuse each other by name instead of exchanging a frame they cannot interpret. Workspace `Discard` stays refused.
