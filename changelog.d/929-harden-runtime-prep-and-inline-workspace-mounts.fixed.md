A bind mount an inline workspace container declares is now resolved through the filesystem instead of compared as a string: a source that does not exist yet still refuses when its parent, or a link in the middle of its path, resolves outside the checkout, and an absolute source is refused rather than mounted. Preparing a task's host bind mounts now reports the Compose input it cannot read or parse, and the directory it cannot create, instead of skipping each and starting the stack against a missing host path; the runtime data tree is only widened for entries the host user created, never through a symlink and never for files another user owns (effigy#929).
