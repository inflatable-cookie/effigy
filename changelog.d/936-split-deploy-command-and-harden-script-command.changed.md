`deploy` now decodes a service `runtime` and a backing-service `mode` once into a closed set, and reports exactly what the manifest declares: the warning-text guess that could turn a `mode = "managed"` resource into a migration notice is gone, and an unsupported `code_ref` kind is refused with the accepted forms instead of planning an unpinned deployment. A Rhai task that calls `effigy.run(...)` or a feature helper now receives the failed command's own sentence and its JSON payload, including the run-control and admission details it used to drop.
