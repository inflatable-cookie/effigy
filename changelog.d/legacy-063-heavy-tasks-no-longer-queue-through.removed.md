**Breaking:** **Heavy tasks no longer queue through a host-run client.** `admission = "heavy"` is metadata only: with no hook set a heavy task runs like any other, CI runners included. When the launcher sets `EFFIGY_ADMISSION_HOOK`, a heavy run calls it, waits bounded for `admit` or `deny <reason>`, and holds the admitted hook under the run's custody. `--host-run-request-id`, `tasks request status|follow`, `HOST_RUN_TOKEN` and `EFFIGY_SCHEDULER_OVERRIDE` are removed; exit 77 is gone.
