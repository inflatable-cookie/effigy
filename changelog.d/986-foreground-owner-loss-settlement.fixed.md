A foreground run whose owner dies no longer leaves its checkout gate held by an orphaned sentinel in an unreadable `unknown` state. The memory guard now observes the owner it recorded by boot and start identity, so a verifiably dead owner ends its cleanup-pin wait: the guard settles the run, releases the gate so the next invocation is admitted, and records one honest journal row — `interrupted` when the run's custody closed, `unknown` with `cleanup: "incomplete"` when a descendant or effect kept it open — never a success and never a process identity. `effigy run status` reports such a run as `interrupted` with `effigy run stop <run>` as its settlement, `effigy run stop` signals nothing for it, waits for that guard and reports the row it wrote, and a new invocation names the gone owner instead of reporting a dead PID as running. An owner whose identity cannot be verified keeps its custody held and still refuses, exactly as before.
