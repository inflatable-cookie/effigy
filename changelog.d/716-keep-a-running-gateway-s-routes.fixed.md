Keep a running gateway's routes converging when a filesystem notification is missed or its first reload is refused (effigy#716). One owned worker is now the only place an observed endpoint snapshot is applied: the directory watcher only signals it, and it re-observes the committed Store snapshot on a five-second interval, retrying a failed observation from one second up to thirty. A missed event therefore no longer strands a route until something publishes again. Re-applying the already applied revision changes nothing - no revision-fence move, no DNS cache clear and no second idle stop - while a changed snapshot still updates the fence, cache, routes and idle generation. An Unknown, unreadable or out-of-contract observation keeps the applied table and reports its cause instead of becoming an empty success. Shutdown and every startup failure after the watcher was installed stop and join the worker.
