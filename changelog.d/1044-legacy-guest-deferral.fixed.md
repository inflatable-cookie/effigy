A container-mode guest running a workspace's legacy production context now hands an undeclared task name to the deferral that context's pinned manifest declares (including the deferral a bundle composes into it) and runs the deferred command in the container, so `effigy prep` in a deferring legacy workspace such as the decodelabs sites reaches the legacy PHP Effigy instead of refusing for host authority. The deferral is resolved from the pinned, digest-verified composed manifest only, keeping the one-hop loop guard and the composer-global `PATH` preference; a deferral that declares `run_in = "host"` and a name no deferral resolves still refuse for host authority.
