Workspace permission preparation now checks the running container's mount table before it scans or chowns a named volume. When a declared named volume has been detached, which happens when a host tool replaces the directory under a VirtioFS mountpoint, Effigy stops with a diagnosis that names the volume and the recovery, `effigy container down && effigy container up --detach`. It no longer walks or changes the host directory underneath, and no longer suggests a `chown -R` that cannot fix a detached mount. The doctor reports the same finding.
