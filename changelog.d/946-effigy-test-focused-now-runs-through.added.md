`effigy test:focused` now runs through `scripts/focused-executable.sh`, which exports `EFFIGY_EXECUTABLE` as this checkout's uplifted `target/debug/effigy` before the selector starts. A focused integration or lib test whose step invokes Effigy no longer fails late as a relative custody executable: an explicit `EFFIGY_EXECUTABLE` is kept, and a checkout that never built the CLI gets one build through the repository's Oxide route (falling back to the instruction if that produces no binary) (effigy#946).
