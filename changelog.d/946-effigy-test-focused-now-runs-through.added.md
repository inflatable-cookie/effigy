`effigy test:focused` now runs through `scripts/focused-executable.sh`, which exports `EFFIGY_EXECUTABLE` as this checkout's uplifted `target/debug/effigy` before the selector builds anything. A focused integration or lib test whose step invokes Effigy no longer fails late as a relative custody executable; an explicit `EFFIGY_EXECUTABLE` is kept, and a checkout with no built CLI refuses up front with the one command that fixes it (`oxide build --bin effigy`) instead of leaving a confusing test failure (effigy#946).
