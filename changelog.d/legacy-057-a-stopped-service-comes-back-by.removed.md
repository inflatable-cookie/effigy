**Breaking:** **A stopped service comes back by itself.** Once `up` has started the stack it asks the runtime for `restart: unless-stopped` on every container whose stack declares no policy of its own; a declared policy (`no`, `always`, `on-failure`, …) wins. The rendered Compose file names no restart policy, because a policy there let nerdctl's restart manager settle a container between Compose's create and start. Effigy no longer hand-starts exited containers by name and issues no `systemctl` command on nerdctl's health-check units.
