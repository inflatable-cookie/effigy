`effigy state plan`, `state apply`, `state capture`, `state capture-set` and `state history` are removed, and so is the `[state.*]` manifest table: a manifest that still declares it now refuses with one actionable error instead of loading. The layered workflow's phase and layer policy, capture profiles, lineage and history reports, state hooks and `.effigy/reports/state/` report files went with them, and `state::plan|apply|capture|capture_set|history` plus the capture/apply context helpers are gone from Rhai. Keep building deployment data with ordinary tasks: `effigy container data seed|dump` for the database, and `effigy state artifact inspect|stage|capture` for plain local and OCI payloads with their immutable digests. The replacement path, including the legacy Acowtancy `[state.legacy-source]` block, is written up in `docs/knowledge/deployment-data-workflows.md`. `[deploy.<env>].state` stays as the environment state label, but a deploy plan no longer reports a retired state stack, and the `before_state`/`after_state` deploy hooks and the `"state"` secret target are removed. Existing `.effigy/reports/state/`, `.effigy/state-captures/` and staged artifact files are left on disk and are no longer read.
