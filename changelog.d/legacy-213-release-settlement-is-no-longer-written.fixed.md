Release settlement is no longer written into a release's receipt. A completed release stays `complete` even when its cleanup has not settled; `effigy release status` shows `Settlement: pending` or `incomplete` with the `effigy release settle <run>` action, and the JSON `run` object gains a `settlement` field only while settlement is pending. An unreadable release journal, a journal that has gone missing while release state remains, or an unreadable record now blocks `release status` instead of reporting no Run.
