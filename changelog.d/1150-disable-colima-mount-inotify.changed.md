Effigy's managed Colima profiles (`effigy`, `effigy-release`) now default to `mountInotify: false` in `colima.yaml` and pass `--mount-inotify=false` on start, and on interactive hosts automatically migrate an already-running managed profile with `mountInotify: true` via a clean restart when zero containers are running (serialized across cooperating Effigy callers via a per-profile `flock` without interrupting running stacks or restarting from non-interactive/CI callers; non-cooperating external `colima nerdctl` or pre-upgrade Effigy starts during the `ps -q` to `colima stop` window cannot be excluded by Colima).
