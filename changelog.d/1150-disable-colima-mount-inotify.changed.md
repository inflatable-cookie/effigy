Effigy's managed Colima profiles (`effigy`, `effigy-release`) now default to `mountInotify: false` in `colima.yaml` and pass `--mount-inotify=false` on start, and on interactive hosts automatically migrate an already-running managed profile with `mountInotify: true` via a clean restart when zero containers are running (while never interrupting active containers or restarting from non-interactive/CI callers).
