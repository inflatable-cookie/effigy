A plain foreground admitted task now has a finite, source-enforced persistence footprint. Its gate files are a fixed set (the task's gate and its checkout-alias spelling, plus the v2 store writer gate) written only through one bounded writer, so a `.gate` body is at most 4096 bytes and a `.scope` marker stays empty; a foreground admission refuses more than four aliased gates. Under admission protocol v2 the one terminal record row is bounded field by field at write time, with `[truncated]` ending a cut field and a fixed 960-byte maximum row, and its expired-row prune is a bounded slice. The store open applies and reads back `journal_size_limit` and `wal_autocheckpoint`, refuses an open whose bounds did not apply, and a closing writable store truncates its write-ahead log inside a short window, so a finished invocation leaves no growing side file (effigy#977).
