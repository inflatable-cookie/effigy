**The gateway keeps one endpoint table in one transaction.** The endpoint quarantine, the v0.14.1 handback and the legacy `routes.json`/`loopback-ips.json`/`ports.json` import are gone; the store is the only source. The route table is also the whole record of loopback ownership: an address is in use exactly when some route references it, and any route write drops routes whose recorded checkout path is gone.
