`effigy container up` now shows a runtime's own output as a bounded rolling window of its latest lines under the stage label instead of printing the whole stream, and the window collapses into the stage's timed result. The terminal points at the run's retained backend log: #277's 64 KiB bound and its `earlier backend output was dropped` marker stand, so it is a bounded tail rather than a complete log. Its path is printed once, labelled `output log (last 64 KiB): <path>`; a failure prints the last ~30 lines and that path before one failure sentence. nerdctl's known unsupported-Compose-field warnings (`Ignoring: … [Labels]`, `[Driver Labels]`, `depends_on … [Required]`) are counted into one summary line rather than echoed. Piped, CI, `--json` and managed-pane output keep their existing behaviour and no JSON field changes.
