A new opt-in `EFFIGY_RUN_DEADLINE_MS` gives one invocation a single absolute deadline, sampled once at process start on the monotonic clock. Admission, the workload and Effigy's own settlement all draw on the same ceiling, with a stated 10-second settlement allowance; a deadline that cannot fit the allowance refuses before anything starts, admission expiry refuses with a typed `deadline` decision before the workload spawns, and a settlement the deadline cuts short is reported as an interrupted run with residue, no completeness footer and exit 124. Nested Effigy children receive only the remaining workload budget, so they cannot extend the parent's deadline. The feature is off by default and writes nothing extra when unset.
