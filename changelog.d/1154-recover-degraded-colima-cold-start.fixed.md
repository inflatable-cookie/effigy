A Colima profile that cold-starts `DEGRADED` because the forwarded SSH-agent boot hook ran before `/run/host-services` existed now recovers in place instead of failing the bring-up. Effigy repairs `/run/host-services/ssh-auth.sock` inside the running VM when a live guest agent socket exists, then starts `containerd` and BuildKit without stopping the VM. For a workspace that mounts the host agent, `container up` repairs a broken forwarded socket when a live guest agent exists, and otherwise refuses to start the workspace and names the profile. Workspaces that do not mount the agent are not checked, and non-interactive callers are never told to restart the profile.
