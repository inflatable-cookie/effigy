A Colima profile that cold-starts `DEGRADED` because the forwarded SSH-agent boot hook ran before `/run/host-services` existed now recovers in place instead of failing the bring-up. Effigy repairs `/run/host-services/ssh-auth.sock` inside the running VM when a live guest agent socket exists, then starts `containerd` and BuildKit without stopping the VM. Where no live agent exists, the refusal names the degraded profile for the host operator, and non-interactive callers are no longer told to restart it.
