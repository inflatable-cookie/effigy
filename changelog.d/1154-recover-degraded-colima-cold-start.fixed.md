A Colima profile that cold-starts `DEGRADED` because the forwarded SSH-agent boot hook ran before `/run/host-services` existed now recovers in place instead of failing the bring-up. Effigy repairs `/run/host-services/ssh-auth.sock` inside the running VM when a live guest agent socket exists, then starts `containerd` and BuildKit without stopping the VM. Where a dangling forwarded socket has no live agent to replace it, `container up` refuses to start the workspace and names the profile, and non-interactive callers are no longer told to restart it.
