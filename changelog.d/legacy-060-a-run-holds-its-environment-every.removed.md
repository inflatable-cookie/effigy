**Breaking:** **A run holds its environment.** Every stop, restart, recreation, reset, handover and idle stop is one transition that refuses while a run holds the environment, except that run's own stop: `container down` under a live `dev` names the holding run and changes nothing. A stack a task starts stops when the last run using it ends, not five minutes later; `container up --detach` keeps a stack running. The lease file, `EFFIGY_HOST_CONTAINER_LEASE_TIMEOUT_SECS`, `EFFIGY_DISABLE_HOST_CONTAINER_LEASE_REAPER` and the hidden `__container-lease-reaper` command are gone.
