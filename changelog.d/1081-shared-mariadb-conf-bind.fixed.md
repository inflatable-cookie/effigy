A shared MariaDB or Postgres render now publishes its bind-mounted init file (and the directories leading to it) with the modes the container's own non-root user needs, instead of whatever the host umask allowed. A restrictive `0077` umask previously left the `.conf` at `0600` inside `0700` directories, so the entrypoint could not read `10-extra-databases.sql` and the service exited 1.
