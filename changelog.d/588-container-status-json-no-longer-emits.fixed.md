`container status --json` no longer emits `services: null` when the runtime is not running. A known-stopped host reports `runtime_running: false` with an empty `services` array. A failed, unparsable, or otherwise unusable Colima status probe fails the command with envelope `error.kind=unavailable` instead of flattening uncertainty into an empty or successful payload (effigy#588). The JSON contract rows for this surface now run against hermetic fake-runtime fixtures.
