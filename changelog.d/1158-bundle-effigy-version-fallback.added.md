Added optional `minimum_effigy_version` and `maximum_effigy_version` compatibility bounds for bundles (`bundle.toml` `[bundle]` and defaults `[manifest]`), with automatic bounded fallback to the newest compatible Git tag when a floating branch tip requires a newer Effigy version, explicit refusal on incompatible `rev` or tag pins before manifest parsing, and clear fallback notices in command notes, `effigy bundle inspect`, and `effigy doctor`.
