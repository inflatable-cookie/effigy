Strict persistence and the reported admission protocol are retired before their first release. `EFFIGY_STRICT_PERSISTENCE`, `effigy run prepare` and `EFFIGY_ADMISSION_PROTOCOL` now return migration guidance. Foreground settlement writes one terminal row to the checkout journal. The hook still uses `EFFIGY_ADMISSION_HOOK`, the `effigy.admission-request.v1` request and the `admit` or `deny <reason>` answer.
