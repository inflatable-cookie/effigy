Resolve ordinary catalog task secrets and the declared vault generate-hook join from the selected task catalog, so a child catalog's task-target keys and relative vault apply for both a root-prefixed selector and a child-cwd run. Nested `secrets init`/`set` pin `--repo` to that catalog; bare help-shaped builtins and `exec` payloads do not. Root-catalog tasks keep the root vault; parent and sibling secret sets are not merged (effigy#662).
