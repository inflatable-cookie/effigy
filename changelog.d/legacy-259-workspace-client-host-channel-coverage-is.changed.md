**Workspace-client host-channel coverage is staged for v0.15.** The required design serves static reads (`effigy tasks`, the pinned identity and the pinned sources) locally from the immutable context generation, without opening a connection or writing. Level 1 requires typed channel requests that the host re-resolves, gates and journals; unsupported guest commands must refuse by name. Neither path may fall back to guest state or a guest engine. Guest `effigy skill run --stdio passthrough` must refuse because it would run a task without host authority. This is a release requirement, not a claim that all Level 1 routes are implemented or qualified. The guest transport, the guest-local container observation and the published session generation are merged; what remains missing is the production activation caller that publishes a qualified locator and the recorded native backend qualification, so host authority reports itself unavailable with the specific missing fact named, and local reads keep working.
