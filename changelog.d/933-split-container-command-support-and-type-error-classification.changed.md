`container_command/support.rs` is now a module of owned jobs instead of one grab-bag: readiness and its declared-health refusal, runtime identity, gateway TCP aliases, pinned host ports, shared-service ensure, shared Compose transport, the runtime commands and volume removal, report annotations, repo scope and the workspace-preparation seam each live in the module that owns them. Failures that used to be classified by matching message prefixes are typed where the error originates: `effigy-containers` decodes an engine's own "not running" answer once into `EngineAbsence` (so a daemon refusal printed on stdout counts), and a gateway endpoint-store refusal carries `EndpointStoreRefusal` into `RunnerError::GatewayEndpointStore`, so the detached activation envelope takes its `failure_kind` from the type rather than the sentence.
