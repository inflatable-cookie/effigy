`effigy state` writes its JSON reports atomically. `write_state_report` and `write_state_context_file` published `latest-*`, history and compatibility reports with a plain truncate-and-rewrite, so `effigy state history` could parse an empty or partial report while another command replaced it and report the generation as malformed; a staged artifact's `effigy-artifact.json` had the same window when the same source was re-staged. Each is now written to a uniquely named temporary file beside its destination, synced, renamed into place and the directory synced, so a concurrent reader sees the complete previous generation or the complete new one (effigy#1001).
