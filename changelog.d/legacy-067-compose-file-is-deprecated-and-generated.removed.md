**Breaking:** **`compose_file` is deprecated and generated Compose stays internal.** Each Compose service is read as a project catalog fragment for this release, with a warning; `effigy container migrate` writes the fragments and checks the render is unchanged. `effigy container eject` is retired, and `.effigy/runtime/` render files are no longer written: read hosts and ports from `effigy container <name> hosts --json` and `effigy container <name> status --json`.
