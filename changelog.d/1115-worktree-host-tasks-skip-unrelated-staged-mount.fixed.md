Host-only tasks and read-only container policy inspection (such as host-alias resolution, `effigy container hosts`, `effigy container status`, `effigy doctor`, volume inventory, and retirement project discovery) now skip live Colima staging-mount probing for unrelated `workspace_source = "staged"` environments whose Colima profile shares no existing writable host mount.
