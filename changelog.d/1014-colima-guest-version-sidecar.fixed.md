Record the pinned guest version beside the executable a container-mode guest runs, so a locally built (stamped) Linux artifact agrees with the context that pins it instead of failing publication with "context probe version or generation differs". A failed publication now names the failing call in the CLI cause and the journal, with a class only where the host can observe one: the staged probe's own refusal class, a host file operation's error kind, or the collapsed exit status the guest command left behind. A collapsed Colima exit is reported as that status and never interpreted, and the guest's own stream is never echoed (effigy#1014).
