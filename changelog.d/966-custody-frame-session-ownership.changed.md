Custody, supervision and the workspace session now each have one owner per mechanism, with the behaviour they already promised. The secret-bearing output path (terminal sanitizing, then redaction, then per-stream projection) is its own module instead of living inside the 2,307-line custody file, and a process intent's stored identity is built from typed values again: its lifetime variant and its grace are encoded as themselves rather than from derived `Debug` text. The supervisor's helper pipes, event stream and owning-client stream share one length-prefixed frame codec that owns the wire bound, short writes and nonblocking retries, so the foreground sentinel no longer carries a second copy. A process-tree termination now reports a process table it could not read instead of treating it as an empty tree: the root's own group is still signalled, and the narrowed termination is stated rather than silent. The environment's workspace session is split into its session identity, its durable activation reservation and its claims/commit plan, and a stored attachment mode is decoded back into its typed mode instead of being compared against a hand-written JSON literal.
