The CLI, UI and TUI now own their shared mechanisms once instead of once per caller. Effigy's colour decision (`NO_COLOR`, then `EFFIGY_COLOR`, then the terminal) lives only in `effigy_ui::theme`, so the CLI banner, the managed renderer and the plain renderer all ask the same function and `NO_COLOR` now wins even under `EFFIGY_COLOR=always`; the banner colours through `effigy_ui::style_text` and the one palette. Step progress is split into owned modules (source, streaming window, terminal hand-over) with no change to what an operator sees, and the multi-process TUI projects its ratatui colours from the same theme instead of keeping a second ANSI-256 table. Every CLI subcommand parses `--repo`, `--json` and help through one shared table, and `tasks unlock`/`tasks cache` hand the built-in task its argv instead of the parser mirroring it a second time (effigy#968).
