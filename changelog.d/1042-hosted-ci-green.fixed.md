Guest preparation publishes the pinned active-version file beside the executable before the digest-addressed store directory is sealed, so a workspace container or an adapter that does not run as root no longer refuses preparation with `mktemp: Permission denied`; a bounded command that runs out of time or overflows an output budget during workspace preparation now reports its own deadline or overflow verdict instead of a generic `workspace_preparation_failed` refusal; an isolated mount point that is itself a symlink is described as that mount point even when the checkout is reached through a host link such as macOS `/var` to `/private/var`; and a parked-sentinel release refusal now prints the exact parseable command `effigy run release <run>` with the run id it names.
