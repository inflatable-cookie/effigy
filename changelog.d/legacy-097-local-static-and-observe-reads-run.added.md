**Local Static and Observe reads run against the pinned snapshot.** Version, the pinned task list and the pinned source identities are read from the context, an immutable rendered snapshot and the mounted checkout alone: no refresh, no enrolment, no host state write. The context pins the root manifest, the source lock, every bundle and catalog source with its digest and each composition fragment. The composed manifest is published once at `/run/effigy/snapshots/<digest>/manifest.toml`, so bundle- and catalog-provided tasks are readable without the guest reading a cache the host did not approve. The pins whose bytes are checkout-visible are digest-checked first, so a checkout that changed since Prepare refuses instead of reading a snapshot the host never approved, and an authority-bearing command refuses as `HostAuthorityRequired` rather than enrolling.
