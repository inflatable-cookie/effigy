The feedback checker no longer hides the code after an escaped character literal. Its escape scan started on the escaped character, so `'\\'` — or a byte literal like `b'\\'` — skipped its own closing quote and blanked every following column through the next quote, letting a fixed-label spinner written after it pass unreported. The scan now recognizes exactly rustc's char literals — one character, or one `\n`/`\x`/`\u{...}` escape closed by the very next quote — and leaves anything else (a lifetime, a malformed or unterminated literal) visible as code, so uncertain input can only over-report, never quietly blank executable code. Escaped-backslash, escaped-quote, malformed-escape and literal/comment-contents controls pin the repaired scan (effigy#594). This restores the documented promise that literal contents are blanked while real code and exact line locations stay visible; no feedback policy or sink exemption changes.
