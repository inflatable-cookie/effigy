Container retirement now stops and removes a profile's containers with one batched `stop -t 2` and one `rm -f`, removes its networks and volumes with one batched command each, and confirms what is gone with one listing per kind instead of a command per resource, so a stack tears down in seconds rather than minutes. Containers still stop before they are removed, and a batch the runtime refuses is retried one resource at a time so each failure keeps its own reason.
