Doctor's manifest shape findings now come from the production manifest parser instead of a schema table maintained beside it, so a key or value is reported exactly when the loader refuses it and each finding names the narrowest refused key path. The `manifest.schema.unsupported_key` and `manifest.schema.unsupported_value` check ids become one `manifest.schema` id, and manifests that declare a task `admission` no longer produce false unsupported-key errors.
