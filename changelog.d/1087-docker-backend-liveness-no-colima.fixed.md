Effigy's runtime liveness, start and exec preparation now ask the backend actually selected instead of always asking Colima. On a Docker backend (Docker Desktop, or any Native Linux host without a `colima` binary) `effigy exec`, routed-task liveness and task exec preparation probe `docker ps` and never spawn `colima`; a Colima host keeps its existing read-only status probe. This fixes the `failed to launch task command 'colima status --profile effigy': No such file or directory` failure that stopped tasks from starting on Native Linux, and an expired caller deadline still refuses before any probe is spawned.
