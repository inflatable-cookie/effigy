On the Colima nerdctl fallback, a repository whose containers receive secrets through the default Compose environment delivery can now run `effigy container up` (attached and detached) and a task's environment apply: each secret-bearing VM Compose launch runs in the retained kernel `Run` that owns its transition, so the interpolation file stays in kernel custody until the Compose group has provably closed instead of the launch being refused. A launch whose custody cannot be admitted still refuses before it starts, its root cause reaches the human output untruncated, and a checkout the Colima profile does not share into the VM is refused with the path and the fix named.
