The config schema templates Effigy prints are now loaded through the manifest loader by a test, and that test found two defects the text assertions could not: the canonical template's `include` override of `docs_policy.indexes.topic` named a path the template never declared, so a verbatim copy failed composition with "unused override path(s)", and the minimal starter declared `[tasks] test`, which the loader has refused since v0.11. The canonical template now carries the docs index it shows being overridden, and the minimal starter maps `check` instead of the reserved word. The minimal starter also no longer includes a docs fragment whose sections it does not document, so both templates now load exactly as printed.
