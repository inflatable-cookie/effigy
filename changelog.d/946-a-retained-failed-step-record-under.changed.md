A retained failed-step record under a configured scratch root stays at `<root>/effigy/failed-steps/<run id>/`, so a root that is itself named `effigy` shows that segment twice. That layout is now documented rather than shortened: the `effigy/` child is the namespace a later bounded sweep descends into, so a record one directory higher would never be retired. The guide names the doubled path an operator on such a root will see (effigy#946).
