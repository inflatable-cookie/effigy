**Workspace entry verifies the prepared guest instead of installing one.** `effigy exec`, `effigy container shell` and a workspace task no longer download, build or copy Effigy into the workspace container. They read the published context and refuse before the command runs when it is missing, pins another version, names an executable that is not installed, or belongs to another container, VM boot or environment generation, naming `effigy container up` to re-prepare. Hybrid mode, which declares no operator workspace, needs none of it. Container-mode Prepare owns acquisition and consumes a produced artifact only: it never builds from a checkout at consumer runtime (contract 052 §8.2, §8.9).
