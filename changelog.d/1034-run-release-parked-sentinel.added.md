`effigy run release <run>` is the supported way to drop a parked sentinel: it re-inventories the run's process group with the same membership the sentinel uses, names every live PID and signals nothing if anything is still alive, and only then asks that sentinel to drop its gates and record `released`. `run status`, a lock-wait timeout, `run stop` and `doctor` (`runtime.parked-sentinel`) name the holding run id, task, sentinel or owner PID, checkout path and state, and print the exact release command when a parked snapshot exists. An older sentinel that never wrote that snapshot cannot handle the request.
