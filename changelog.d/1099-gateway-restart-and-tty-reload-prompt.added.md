`effigy gateway restart` stops the running gateway, if one runs, and starts this build, so an upgraded binary can take over a daemon that still serves an older one without remembering two commands; `--json` reports `action: "restart"` with the previous and the current build. `effigy gateway status` now names the running build in its text output and, when that build is not this binary, prints a structured warning whose next action is `effigy gateway restart`. On an interactive terminal, `effigy dev`, `effigy container up` and `effigy gateway up` ask once whether to reload an outdated gateway and reload it on this build when the answer is Enter, `y` or `yes`; a non-interactive run, `--json`, CI and fixture or test processes never prompt, never read stdin and never replace the machine gateway, printing the same warning instead.
