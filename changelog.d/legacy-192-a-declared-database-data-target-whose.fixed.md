A declared database data target whose service is `shared = true` now seeds and dumps in that service's own machine-wide Compose project and render, so `stack` and `hybrid` declarations of one shared identity feed one database and volume instead of failing against the checkout-local Compose that removed the service. The selected environment's declarations are used, so `--name hybrid` seeds hybrid's target rather than the manifest default. Before the first statement Effigy proves the expected render's every file (Compose input and bound configuration) is present, readable and unchanged, and that the runtime reports exactly one running container of the declared service in the declared project from the declared render digest; a missing, unreadable or altered render file, stopped or absent container, stale render, several running containers, an unreadable runtime or environments that declare the same service with different shared identities refuse and name the project and recovery command. A data step never publishes a render, starts or replaces a shared service — its own or an unrelated one — or falls back to a local service of the same name; a seed that selects a shared target skips its environment activation, and every activation a data seed performs (including a routed app-defined `data:seed` task) leaves shared services alone. A seed whose environment has shared services and is stopped refuses and names `effigy container up <NAME>` instead of bringing it up, because that would reconcile them; an environment with no shared services keeps its prior bring-up behaviour, and the decision is made per activated environment, so a catalog-routed step cannot start another catalog's shared service. The exec forwards the client credential by name only: each call creates its own private 0600 file that the Compose client sources before it runs, on the host or through the Colima VM transport, and removes it afterwards, so concurrent data commands never share a credential path and no value reaches a command line or a report. Every shared Compose call is bounded (15 minutes for a control call, one hour for a data exec) and takes its process group with it on expiry, while the complete output still feeds the dump artifact. Unshared targets keep the checkout-local route.
