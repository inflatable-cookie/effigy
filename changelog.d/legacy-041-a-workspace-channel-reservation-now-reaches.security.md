A workspace channel reservation now reaches exactly the run it reserved: the dispatcher's `AdmissionTicket` travels unchanged through the engine supervisor into the task run, which admits it with `Run::begin_admitted` under the ticket's own id and never mints, swaps or re-begins one. Engine-internal, standalone, nested, caller-keyed and shared-lock run shapes refuse a ticket before any effect instead of admitting a second run; ordinary runs keep their existing admission path.
