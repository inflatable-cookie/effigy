Bundle sources refresh once, when a command starts, and the command keeps the bytes it selected until it exits: a refresh by another command never removes them, and a running task or managed process no longer switches sources mid-run. Source paths in running steps are no longer rewritten. The machine-wide known-version hint is gone, so a read reports a behind source only when its declaration changed, and setting `EFFIGY_GIT_BUNDLE_REMOTE_CHECK_TTL_SECS` no longer warns.
