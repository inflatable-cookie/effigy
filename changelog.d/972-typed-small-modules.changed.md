Container detection, OCI artifact failures, runtime failures and container probes now report typed facts instead of collapsing them: a container probe that could not be read is reported as unknown rather than as "not a container", an unreachable registry or missing capability is reported as an unavailable environment rather than as a refused or fabricated command, a container that answers neither shell probe is refused instead of silently running through `/bin/sh`, and state report names use one UTC calendar (`chrono`) so a clock before the epoch keeps its own date. `effigy-core::repo` and the exec probe spec are now the single owners of path identity and probe results, replacing three duplicate `canonicalize_or_original` copies and the string-keyed probe map.
