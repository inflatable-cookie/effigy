The remaining wall-clock-bounded proof fixtures no longer let a loaded host decide their outcome, so a candidate QA run reports the behaviour each test asserts instead of a spent budget. The kernel HTTP probe and its integration counterpart scale their fixture request budgets with measured host load instead of a flat 200/250ms. The process-supervisor proofs wait for the event they assert under a load-scaled guard instead of spending a fixed number of short receive slices, and the kernel, container and gateway fixtures that wait on another thread or a peer now use the same load-scaled floor. The named checks, their assertions and every product timeout are unchanged (effigy#994).
