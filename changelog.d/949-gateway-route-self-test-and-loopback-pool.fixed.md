`container up` and `dev` now prove a newly registered TLS route is servable: they complete a local TLS handshake for the route's SNI and, on failure, name the running gateway build and the `effigy gateway down` then `effigy gateway up` remedy instead of leaving the browser to fail. The loopback alias pool grows to 250 addresses, with `gateway setup` materialising one `lo0` alias per address so worktree churn no longer exhausts it. An isolated mount point reached through a symlinked ancestor is now refused exactly like a symlink at the mount point itself, so mount preparation never creates outside the checkout.
