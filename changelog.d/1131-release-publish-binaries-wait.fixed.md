`effigy release:publish:binaries` (`scripts/release/checks.sh publish-binaries`) now identifies the newly dispatched `release-binaries.yml` workflow run ID and waits for it to complete via `gh run watch` (with a `gh run view` polling fallback and an optional `--no-wait` / `EFFIGY_RELEASE_NO_WAIT=1` opt-out for manual dispatch), failing before `verify` if the workflow concludes non-success instead of returning immediately after dispatch.
