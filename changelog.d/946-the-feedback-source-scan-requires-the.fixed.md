The feedback source scan requires the opening brace of a `\u{...}` escape. A brace-less spelling such as `'\uAB}'` is malformed Rust and is now left visible as code, the same way every other unrecognised literal is, instead of being blanked as if it were a character literal; its docstring no longer claims to model rustc's whole char-literal grammar, only the notation it checks (effigy#946).
