A failing managed host listener withholds only its own route. `container up` now decides exposure per declared route target: a listener that answers its readiness request with the wrong status, or never opens its port, keeps its own route absent while the container's verified routes and every other ready listener stay published. `container up --detach` reports the partial exposure in text and JSON, naming the published routes and the withheld listener with its observed status and a bounded, redacted child-output tail, instead of the whole activation's readiness and exposure as unverified. A definite status mismatch is refused as soon as it is observed rather than spending `readiness.timeout_secs`, and a still-closed port's progress line carries the child's own bounded output tail. Progress and activation-budget refusals name the supervisor's actual probe phase: an open port with no HTTP status keeps its running readiness clock and is never described as closed. A port that never opens is bounded by the bring-up's observation budget instead of holding `up` open, and its progress carries that same bounded, redacted tail. The timed-out generation is settled before the command returns, so it cannot publish a route after the report. A listener the activation did not start is reconciled against its own published generation and the current declaration (domain, TLS, bind, live readiness), so only a generation that still serves the declared target keeps its route; a generation that fails that check is settled and its route withdrawn, and a withheld listener's `depends_on` chain withholds every dependent route, settling previously running dependents under the current declaration even after the activation budget expires. Retrying listener failures are settled too, including failures before the first child, so detach cannot hang waiting for them to become active or let them publish a late route. An incomplete settlement remains a refusal. A log line whose `key=` marker falls outside the bounded read window is dropped rather than printed unredacted (effigy#455).
