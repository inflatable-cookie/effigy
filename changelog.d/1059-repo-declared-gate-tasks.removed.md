**Breaking:** Release gates no longer carry a built-in GitHub hosted-evidence mode. `reuse-hosted-evidence` on a `[release.gates]` entry, the `[release.hosted-evidence]` table, the `awaiting-hosted-evidence` Run status, and the gate result's `reused`, `hosted_run_url`, `hosted_head_sha` and `hosted_repository` JSON fields are gone. Declare a provider-specific gate as an ordinary repo task instead — `ci = { task = "release:ci-evidence" }` in `[release.gates]`, with the task in `[tasks]` — and read the exact commit it must prove from `EFFIGY_RELEASE_COMMIT`. A gate without evidence now fails where it runs, so nothing publishes behind it and `release resume` re-runs that gate; Effigy's own release keeps its `ci` gate as the `release:ci-evidence` task.
