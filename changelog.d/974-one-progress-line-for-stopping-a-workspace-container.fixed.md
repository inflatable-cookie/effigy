Stopping a workspace container is one progress line instead of three stacked spinners. Leaving a workspace used to draw `stopping workspace system`, the runtime's `stopping the stack`, and the transition's `Checking environment` at once, all timing the same stop; the outermost transition now keeps the single step while the runtime's own stopping and removing reports arrive as that step's sub-step text, so a slow stop still names the service holding it up. The stop-phase title keeps the lowercase sub-step wording the runtime reports, matching the sibling steps in the same paths. A failed stop still returns the teardown's own failure, naming the layer that failed and why (effigy#974).
