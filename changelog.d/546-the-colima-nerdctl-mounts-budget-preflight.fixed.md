The Colima nerdctl mounts-budget preflight no longer refuses before commands that never apply Compose. The admission guard is apply-time: activation and `up`, pull-production, workspace artifact builds, runtime activation prep and workspace sessions still refuse before their apply, while `container status`, `container logs`, data list, cache list, cache prune, data export and import and attach-only exec and shell sessions read or attach to an already-running stack whose mounts were admitted when it was created, so a query or session can no longer fail on a budget its operation would never consume (effigy#546).
