A custody anchor no longer ignores SIGTERM: an idle `__kernel-anchor` exits within a bounded grace when a harness stops the tree it started, and a run that completes still retires its anchor during settlement, so a settled run leaves none. SIGINT and SIGHUP stay ignored, because a terminal delivers them to the whole foreground group. Losing the anchor on TERM while workload members remain stays the existing `Unknown` outcome; no numeric group signal is inferred (Q-014).
