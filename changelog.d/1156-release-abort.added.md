`effigy release abort [<run>] [--yes] [--json]` discards an unpublished failed release Run. It removes the Run's record, receipt and candidate and clears its checkpoint, so the next `effigy release run` starts a fresh Run instead of resuming the failed one. Abort refuses, changing nothing, when the release commit was pushed, the Run is complete, or any publish target is published, failed or unknown. It never runs `git reset`: the report names the `git reset --keep <source>` that discards an unpushed prepared commit still on `HEAD`.
