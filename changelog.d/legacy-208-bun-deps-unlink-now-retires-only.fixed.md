Bun `deps unlink` now retires only the named consumer's claims when that checkout is already gone, instead of no-op'ing and leaving the worktree claim behind. Each claim records the checkout that wrote it, so `--repo` recovers a nested Bun root without reaching into an independently nested checkout, and a claim without that evidence is reported with the root to name. Recovery without the ledger releases claims only: it never inspects, removes or verifies a consumer `node_modules` link, because a claim names a registration rather than the consumer tree that owns a link, so an unreadable or malformed consumer path cannot block releasing the claim.
