The workspace host authority channel's protocol is implemented in the kernel (`crates/effigy-kernel/src/workspace_channel.rs`): §8.11's length-prefixed v1 frames and limits, a server-pin check that runs before any credential crosses, hello/version/digest negotiation, session-bound capabilities and enrolment, and typed `observe`/`invoke`/`attach`/`cancel`/`detach` dispatch. A request id is looked up and reserved before any engine is asked to admit it, so a retry returns the recorded admission, its recorded outcome, or `unknown` — never a second run — across a reconnect or supervisor restart. No production activation caller or native backend qualification is wired to it yet; the pinned TLS transport, the guest client and the guest dispatch are merged (contract 052 §8.11).
